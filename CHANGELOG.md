Initial MVP scaffold.

### Added

- `createBus<TEvents>()`
- Exact event subscriptions with typed payloads
- `*` global wildcard subscriptions
- `prefix:*` namespace wildcard subscriptions
- `on`, `off`, `once`, `emit`, `emitAsync`, `clear`, `listenerCount`
- Runtime tests and TypeScript type-safety tests
- README, examples, CI workflow, and npm package configuration
